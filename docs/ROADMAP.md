# NoGaReader 功能补齐路线图

> 对照对象：`cp.md`（EPUB+ Reader 功能分析）
> 当前版本基线：`1.1.0`（Phase A–D 基础已落地）
> 产品定位：本地免费的多格式阅读 + 文档编辑 + 批量转换 + 可选云同步套件
> **唯一明确不做：商店订阅 / 付费门控 / 功能上锁**

## 0. 原则与边界

### 必须遵守

1. 核心能力全部免费：阅读、转换、打印、主题、编辑、同步不设付费墙。
2. 本地优先：默认数据在本机；云同步为可选、可关闭。
3. 洁净室：参考公开功能，不复制竞品代码/资源/品牌/界面。
4. 统一模型：新格式进入 `ReaderSession` / `DocumentLoader` 边界；转换与编辑有独立子系统。
5. 安全默认：压缩包/HTML/脚本/路径穿越继续有资源上限；同步需加密与明确授权。

### 明确不做

| 能力 | 决策 |
|---|---|
| Microsoft Store 订阅 / 内购 | 不做 |
| 免费次数限制（如“仅 3 次转换”） | 不做 |
| 打印/主题/去广告等高级版门控 | 不做 |
| 强制登录才能阅读 | 不做 |

### 明确要做（相对旧路线图的修正）

| 能力 | 决策 | 说明 |
|---|---|---|
| 内嵌 Calibre 转换引擎 | 要做 | 随包附带或首次引导安装本地转换运行时，不依赖用户“碰巧装过 Calibre” |
| 完整 Word 兼容编辑器 | 要做 | 查看 + 编辑 + 另存为，不只读预览 |
| 云同步 | 要做 | 书库元数据、阅读进度、批注、设置可选同步；源文件默认可选同步/仅链接 |

### 体积与架构取舍

内嵌 Calibre + 文档编辑器会显著增大安装包（竞品约 800MB+）。接受此代价，但模块仍隔离：

```text
NoGaReader.exe（WPF 主壳，免费全功能）
├─ 阅读子系统（现有 WebView2 + 各 Loader）
├─ 转换子系统（内嵌 Calibre ebook-convert 及依赖）
├─ 文档编辑子系统（Word/RTF/ODT 完整编辑）
└─ 同步子系统（可选云后端，默认可完全离线）
```

## 2. 分阶段计划

### Phase A — V0.8 内嵌转换引擎与 Kindle 阅读

**状态：基础已落地（引擎探测 / Kindle 路由 / 批量转换 UI）；完整 Calibre 二进制随包附带仍待发布打包。**

**目标**：不依赖用户预装 Calibre，也能转换并打开 MOBI/AZW3。

#### A1. 内嵌 Calibre 运行时

- 发布形态二选一（实现时定案，优先 1）：
  1. **随安装包附带**精简 `ebook-convert` 运行时（推荐，开箱即用）
  2. 首次使用时下载到 `%LOCALAPPDATA%\NoGaReader\engines\calibre\`
- 许可证：在“关于/第三方”页展示 Calibre GPLv3 及依赖声明
- 服务：
  - `IFormatConverter`
  - `EmbeddedCalibreConverter`
  - `CalibreRuntimeLocator`（内嵌路径优先，可手动覆盖）

#### A2. MOBI / AZW / AZW3 阅读

- 打开：源格式 → 内嵌转换 → 缓存 EPUB → 现有 `EpubLoader`
- 缓存键：路径 + size + mtime（或内容哈希）
- 书库扫描识别这些扩展名

#### A3. 批量转换页（免费无限）

- 多文件列表、拖放、统一/逐项目标格式
- 输出到指定目录或源目录旁
- 状态：准备 / 转换中 / 完成 / 失败；可打开文件或目录
- 首批输出：`PDF` `EPUB` `MOBI` `AZW3` `DOCX` `FB2` `RTF` `TXT` `HTMLZ` `ZIP`
- 首批输入：竞品常见集合的可落地子集（EPUB/MOBI/AZW/PDF/DOCX/HTML/TXT/CBZ 等）
- 并发与进度：隐藏子进程，捕获 stdout/stderr

#### A4. 验收

- 干净机器（无系统 Calibre）可完成转换与 MOBI 打开
- 批量 10 文件不崩溃；失败可重试
- 无任何次数限制 UI/逻辑

**交付物**：`0.8.0`

### Phase B — V0.9 完整文档编辑器

**状态：基础已落地（Open XML DOCX/RTF/TXT/HTML 编辑器 + 打印/查找）。商业级排版保真与 DOC/ODT 原生编辑后续增强。**

**目标**：达到竞品“查看文档 / Word 编辑器”级能力，且免费。

#### B1. 技术选型（实现前 spike 1–3 天）

候选（按可行性评估后锁定其一）：

| 方案 | 优点 | 代价 |
|---|---|---|
| **Syncfusion / Telerik / DevExpress 类商业控件** | 功能全、排版强 | 需商业授权（应用仍可对用户免费） |
| **Open XML + 自研编辑壳** | 无运行时授权费 | DOCX 保真度与工期压力大 |
| **嵌入 LibreOffice / 外部引擎** | 格式广 | 体积与进程编排复杂 |

推荐默认路径：**成熟 .NET 文档控件（商业授权给开发者）+ 用户侧完全免费**。

#### B2. 功能范围（V0.9 必达）

- 打开：DOC、DOCX、DOT、DOCM、RTF、TXT、HTML/MHT、ODT、XML
- 编辑：正文、标题样式、字体、段落、列表、表格、图片
- 另存为：DOCX、DOC、RTF、TXT、HTML、PDF、ODT（能做多少做多少，不足格式可经转换引擎）
- 打印与打印预览
- 查找替换、字数统计
- 与主壳统一主题/最近文件/拖放

#### B3. 架构

```text
MainWindow / 文档页
  └─ DocumentEditorHost
       ├─ IDocumentEditor（抽象）
       └─ <选定控件实现>
```

阅读器与编辑器进程可同进程宿主；若稳定性差再拆子进程。

#### B4. 验收

- 打开真实 DOCX，编辑后另存，用 Word/WPS 回读无明显损坏
- 打印预览可用
- 与阅读模块互不拖垮（异常隔离）

**交付物**：`1.0.0`

---

### Phase C — V1.0 桌面产品化 + 更多阅读格式

**状态：基础已落地（单实例 IPC、HKCU 文件关联、阅读打印、CBT、CHM/XPS/DJVU）。正式 MSIX 安装包后续增强。**

**目标**：安装、关联、固定版式补齐。

#### C1. 单实例 + 二次打开传参

- Mutex + 命名管道/本地 socket
- 文件关联唤起已运行实例

#### C2. 安装包与文件关联

- MSIX 和/或传统安装器
- 关联：电子书、漫画、PDF、文档、Kindle 格式等
- 开始菜单、卸载、图标、第三方许可证

#### C3. 打印（阅读侧）

- EPUB/FB2/MD/TXT：WebView2 打印
- PDF：内置打印
- 漫画：当前页/范围打印

#### C4. 格式扩展

- CBT（tar 漫画）
- DJVU、XPS/OXPS（库或内嵌渲染）
- CHM（受控 HTML + TOC）

#### C5. 验收

- 双击 `.epub` / `.docx` / `.mobi` 正确路由到阅读或编辑
- 安装卸载干净

**交付物**：`1.0.0`

### Phase D — V1.1 云同步（可选、免费）

**状态：基础已落地（文件夹/网盘目录同步进度与批注）。WebDAV/S3 与官方账号服务后续增强。**

**目标**：多设备同步进度与批注；默认仍可完全离线。

#### D1. 同步内容分层

| 层级 | 内容 | 默认 |
|---|---|---|
| L1 轻量 | 阅读进度、书签、高亮、笔记、设置、书库元数据 | 可选开启 |
| L2 中量 | 封面、转换缓存索引 | 可选 |
| L3 重量 | 源电子书文件本体 | 默认关，用户显式选择 |

#### D2. 后端策略

- 抽象 `ISyncProvider`：
  - 第一实现：WebDAV / S3 兼容（用户自备网盘/对象存储）——隐私友好、无强制账号
  - 第二实现：官方同步服务（若后续自建，仍免费额度策略另定，但应用内不设功能付费墙）
- 传输：HTTPS；本地密钥加密敏感字段；冲突：按时间戳 + 用户选择合并

#### D3. UI

- 设置：登录/连接提供方、选择同步范围、立即同步、冲突列表
- 状态栏：同步中 / 已同步 / 离线
- 首次：明确“不同步则 100% 本地”

#### D4. 验收

- 两台机器 L1 同步后进度与批注一致
- 断网可继续阅读
- 关闭同步后无后台上传

**交付物**：`1.1.0`

## 4. 每阶段 Definition of Done

- [ ] 无付费、无试用次数、无功能锁
- [ ] 新能力有清晰服务边界（转换 / 编辑 / 同步 子系统）
- [ ] 内嵌第三方引擎有许可证展示
- [ ] Smoke 或专项测试覆盖成功 + 关键失败路径
- [ ] README / ARCHITECTURE / 本路线图同步
- [ ] 关闭云同步时零网络依赖可完成阅读与转换
